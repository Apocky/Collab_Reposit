# Chaos Tarot — YouTube channel plan

Work tracking for building the Chaos Tarot (chaos-tarot.com) YouTube channel, produced with the `Apocky-plan` skill (`.claude/skills/Apocky-plan/`).

| File | What it is | Read when |
|------|------------|-----------|
| `BRIEF.md` | The context frame: tagged facts, brand voice, shipped card names, assets, business context, audience research, assumptions A1–A8, contradictions | First, always |
| `QUESTIONS.md` | Batched questions for Apocky with the default assumed if unanswered | Before executing anything |
| `PLAN.md` | Positioning, pillars, formats, weekly operating cadence, metrics, risks, countercase and falsifier, review log | Deciding what and why |
| `ROADMAP.md` | 90-day phased timeline with an exit gate, falsifier and rollback per phase; week-by-week table | Deciding when |
| `ISSUES.md` | The tracker. `CT-YT-NNN` rows with acceptance oracle, falsifier, rollback, provenance | Picking up work |
| `DECISIONS.md` | Append-only ledger: decision, strongest rejected alternative, falsifier | Before reversing a choice |
| `SESSION_HANDOFF.md` | Exact restart surface for the next session | Resuming |
| `prompts/SOURCE_PROMPTS.md` | Verbatim transcription of the source thread's prompts, with screenshots | Checking fidelity to the source |
| `sections/01…07-*.md` | One deep section per source prompt (the evidence base the plan links to) | Going deep on one area |

Status vocabulary in `ISSUES.md`: `todo · doing · blocked · review · done · dropped`. Provenance tags everywhere: ✓ VERIFIED · ◐ INFERRED · ○ REPORTED · ⊘ ASSUMED.

Product repo (private, read-only reference for this plan): `Apocky/The-Chaos-Tarot`.
